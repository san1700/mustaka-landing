# Design System Mustaka EduOS

## Overview
Design system untuk Landing Page Mustaka EduOS berorientasi B2B EdTech modern dengan kesan bersih, kredibel, dan berenergi positif.

## Colors
- **Primary Accent (`#5EC234`)**: Digunakan untuk tombol CTA utama, teks sorotan hero, ikon aktif, dan indikator status live.
- **Deep Charcoal (`#11181C`)**: Digunakan untuk headline utama, teks isi kontras, dan kontainer gelap pilar yayasan.
- **Soft Mint Green (`#EFF7EC`)**: Digunakan untuk permukaan kartu fitur 4-grid, badge kategori, dan pre-footer CTA banner.
- **Forest Green Gradient (`#133019` ke `#214D28`)**: Digunakan untuk mid-page problem banner.
- **Canvas (`#FAFAFA` / `#FFFFFF`)**: Background utama halaman yang bersih dan terang.

## Typography
- **Font Utama**: *Plus Jakarta Sans* dengan ketebalan 400 (regular), 500 (medium), 600 (semibold), 700 (bold), dan 800 (extrabold).
- **Font Kode / Monospace**: *JetBrains Mono* untuk NISN, audit logs, dan ID teknis.

## Elevation & Depth
- Border halus `#E2EAE6` dan `#C4E3B9` dipadukan dengan bayangan lembut (`shadow-sm`, `shadow-md`, `shadow-xl`) untuk memberikan hierarki kedalaman visual.
- Floating badges menggunakan efek animasi `animate-float` yang memberikan kesan antarmuka hidup.

## Components
- **Sticky Navbar**: Header dengan elevated shadow saat di-scroll dan akses cepat ke modal demo.
- **Portal Browser Card**: Mockup antarmuka kesiswaan 360° interaktif murni kode Tailwind.
- **4-Grid Mint Feature Cards**: Kartu fitur berlatar mint dengan tombol panah bulat interaktif.
- **Pill Badges**: Badge radio dan floating tag beraksen hijau dan mint.
- **Demo Scheduling Modal**: Dialog formulir cepat dengan prefix WhatsApp `+62` dan redirect terstruktur.
